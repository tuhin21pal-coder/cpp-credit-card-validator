# Credit Card Validator (C++)
A simple C++ program that validates credit card numbers using the Luhn Algorithm. It checks user input, calculates the sum, and determines whether the entered number passes the Luhn validation test.

# Features
Validates credit card numbers using the Luhn Algorithm.
<br>
Checks whether the input contains only digits.
<br>
Rejects letters, spaces, and special characters.
<br>
Uses separate functions for checksum calculations.
<br>
Handles large card numbers using strings instead of integers.
